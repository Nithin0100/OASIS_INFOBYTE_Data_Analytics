# Oasis Infobyte Internship — Task 04: Google Play Store Analysis

## Objective
To analyze Google Play Store applications using data analytics techniques to understand app categories, ratings, installations, pricing strategies, and user reviews.

## Dataset
- Dataset: Google Play Store Apps and User Reviews
- Original files: `googleplaystore.csv`, `googleplaystore_user_reviews.csv`
- Tools: Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook, Google Colab

## Work Completed
- Loaded and inspected the apps and user reviews datasets.
- Checked missing values and duplicate records.
- Cleaned ratings, installation counts, reviews, prices, and app sizes.
- Analyzed application categories and rating distributions.
- Identified apps with the highest recorded installation counts.
- Compared free and paid applications.
- Analyzed paid app pricing patterns.
- Examined content ratings across applications.
- Visualized relationships between ratings, reviews, installations, and prices.
- Analyzed the distribution of user review sentiments.
- Examined sentiment polarity across user reviews.
- Summarized review sentiment by application.
- Created visualizations to identify patterns in app popularity and user satisfaction.
- Exported cleaned datasets and sentiment summaries to CSV files.

## Files
- `Oasis_Infobyte_L2_Task_04_Google_Play_Store_Analysis.ipynb` — Jupyter notebook containing the code, visualizations, and analysis.
- `googleplaystore.csv` — Google Play Store application dataset.
- `googleplaystore_user_reviews.csv` — user reviews dataset.
- `googleplaystore_cleaned.csv` — cleaned application dataset generated by the notebook.
- `googleplaystore_reviews_cleaned.csv` — cleaned reviews dataset generated by the notebook.
- `googleplaystore_sentiment_summary.csv` — aggregated app-level sentiment results generated by the notebook.

## Conclusion
The project uses Python-based data analysis and visualization to explore Google Play Store applications and user reviews. It examines application categories, ratings, installation trends, pricing, and review sentiment to identify patterns related to app popularity and user satisfaction.
