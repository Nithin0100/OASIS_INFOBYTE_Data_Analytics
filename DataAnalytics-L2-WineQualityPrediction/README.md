# Oasis Infobyte Internship — Task 02: Wine Quality Prediction

## Objective
To analyze the red wine quality dataset, perform exploratory data analysis, and build machine learning classification models to predict wine quality based on physicochemical properties.

## Dataset
- Dataset: Red Wine Quality dataset
- Original file: `winequality-red.csv`
- Tools: Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Google Colab

## Work Completed
- Loaded and inspected the dataset.
- Checked missing values and duplicate records.
- Analyzed descriptive statistics and wine quality distribution.
- Visualized chemical feature distributions.
- Created a correlation heatmap to understand relationships between features.
- Grouped wine quality scores into Low, Medium, and High categories.
- Split the dataset into training and testing sets using stratified sampling.
- Trained Random Forest, SGD Classifier, and Support Vector Classifier (SVC) models.
- Evaluated models using accuracy, precision, recall, F1-score, classification reports, and confusion matrices.
- Visualized feature importance using the Random Forest model.
- Created a comparison table to evaluate model performance.

## Files
- `Oasis_Infobyte_L2_Task_02_Wine_Quality_Prediction.ipynb` — Jupyter notebook containing the code and analysis.
- `winequality-red.csv` — red wine quality dataset.

## Conclusion
The project applies exploratory data analysis and machine learning classification techniques to predict wine quality categories. The performance of three classification models is compared using evaluation metrics to identify the most suitable model for this dataset.
